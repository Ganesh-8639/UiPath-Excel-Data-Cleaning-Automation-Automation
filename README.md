# Excel Data Cleaning Automation

## Description

A UiPath-based automation that cleans and validates Excel data by detecting missing and invalid records, removing duplicate rows, standardizing data, and generating a Cleaning Summary Report.

## Features

- Cleans and standardizes Excel data
- Detects missing data
- Validates phone numbers and email addresses
- Removes duplicate records
- Adds data quality status
- Generates a Cleaning Summary Report
- Saves the cleaned data into a separate Excel file

## Technologies Used

- UiPath Studio
- Excel
- DataTable
